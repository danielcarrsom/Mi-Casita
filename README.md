# Mi Casita

Voice-first financial planning companion for Latino immigrants in New York.

`index.html` is a single-file clickable prototype of the 12 core screens
(onboarding 1–8, then Add spending, My help, Learn and Helper mode).
Open it in a browser. The mic is simulated: tap it to see the listening
state and the recognized answer. Speaker icons use the browser's
speech synthesis when it is available.

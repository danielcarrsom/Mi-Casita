# Mi Casita

Voice-first financial planning companion for Latino immigrants in New York.

`index.html` is a single-file clickable prototype of 16 screens:
onboarding 1–8, then Add spending, My help, Learn and Helper mode, plus
four tools adapted from the Claro demo in Mi Casita's voice-and-pictures
style: Send money home (13), My business (14), My week (15) and Letters (16).
Open it in a browser. The mic is simulated: tap it to see the listening
state and the recognized answer. Speaker icons use the browser's
speech synthesis when it is available.
